Primeduel backup

A private backup tool of the Primeduel project

Primeduel backup copies the nightly backups of the Primeduel game server to the Google Drive of the project owner and reads them back to check that a backup can be restored. It is used only by the project owner and is not offered to anyone else.

What it does

  • Every night it uploads two files to the owner's Google Drive: a database dump and an archive of the server settings.
  • It keeps the last 30 copies of each kind and deletes older copies it created.
  • Once a month it downloads a copy and checks that the database can be restored from it.

Access to Google Drive

The tool asks for one permission, drive.file: access only to the files and the folder that this tool created itself. It cannot see or change any other files in the owner's Google Drive and does not read the profile, contacts or email.
