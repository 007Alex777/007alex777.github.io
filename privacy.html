Privacy Policy

Primeduel backup. Effective date: 11.11.2026

Who we are

Primeduel backup is a private tool of the Primeduel project. It is run by the project owner for their own backups and is not offered to other users. Home page: Primeduel backup.

What Google data the tool accesses

The tool uses one Google permission, drive.file. With it the tool can access only the files and the folder it created itself in the owner's Google Drive. It does not access other files, the Google profile, email, contacts or any other Google user data.

How the data is used

  • The tool uploads backup files of the Primeduel game server to a folder in the owner's Google Drive.
  • It lists and downloads these files to check that a backup can be restored.
  • It deletes its own old copies, keeping the last 30 copies of each kind.

Storage and protection

The backup files stay in the owner's Google Drive. The access token is stored only on the Primeduel server in a file readable only by the server administrator. The tool has no other copies of Google data.

Sharing

Data received from Google APIs is not sold, shared or transferred to third parties, and is not used for advertising, analytics or training of AI models. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Access can be removed at any time on the Google Account permissions page. Deleting the backup folder in Google Drive removes all copies made by the tool.

Changes

Changes to this policy are published on this page with a new effective date.
